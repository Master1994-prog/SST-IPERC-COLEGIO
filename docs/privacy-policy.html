Política de Privacidad

SST EduRisk

Aplicación móvil de Seguridad y Salud en el Trabajo e IPERC

Última actualización: 7 de septiembre de 2026

Resumen: SST EduRisk utiliza la información necesaria para permitir la autenticación de usuarios, gestionar información de Seguridad y Salud en el Trabajo (SST), elaborar matrices IPERC y permitir el funcionamiento de determinadas funciones tanto en modo online como offline.

1. Introducción

La presente Política de Privacidad describe cómo la aplicación móvil SST EduRisk recopila, utiliza, almacena y protege la información necesaria para proporcionar sus funcionalidades.

SST EduRisk ha sido desarrollada como una herramienta de apoyo para la gestión de Seguridad y Salud en el Trabajo (SST), incluyendo procesos relacionados con la identificación de peligros, evaluación de riesgos y determinación de controles (IPERC).

Al utilizar SST EduRisk, el usuario reconoce haber leído esta Política de Privacidad.

2. Información que puede tratar la aplicación

Dependiendo de las funciones utilizadas y del perfil del usuario, SST EduRisk puede tratar las siguientes categorías de información:

2.1. Información de cuenta y autenticación

  • Identificador del usuario.
  • Nombre de usuario.
  • Rol o nivel de acceso asignado.
  • Credenciales utilizadas para iniciar sesión.
  • Información técnica de la sesión de autenticación.

Cuando el usuario inicia sesión mediante conexión con el servidor, sus credenciales son utilizadas únicamente para verificar su identidad y autorizar el acceso a las funciones correspondientes.

2.2. Información relacionada con SST e IPERC

La aplicación puede almacenar y procesar información introducida por usuarios autorizados relacionada con la gestión de Seguridad y Salud en el Trabajo, como por ejemplo:

  • Instituciones y sedes.
  • Áreas y puestos de trabajo.
  • Procesos y actividades.
  • Peligros identificados.
  • Consecuencias asociadas.
  • Controles de seguridad.
  • Equipos de protección personal.
  • Evaluaciones de riesgos.
  • Matrices IPERC.
  • Seguimientos y observaciones.
  • Información relacionada con mapas de riesgo.
  • Registros necesarios para las funcionalidades de SST.

2.3. Datos almacenados para funcionamiento offline

SST EduRisk incluye funcionalidades que permiten continuar trabajando temporalmente cuando el dispositivo no dispone de conexión a Internet.

Para ello, determinada información necesaria para el funcionamiento de la aplicación puede almacenarse localmente en el dispositivo.

Entre esta información pueden encontrarse:

  • Identificador del usuario autorizado.
  • Nombre del usuario.
  • Rol del usuario.
  • Datos operativos necesarios para trabajar sin conexión.
  • Cambios pendientes de sincronización.

3. Seguridad de las credenciales

SST EduRisk aplica mecanismos de almacenamiento seguro para determinada información de autenticación.

Para permitir la validación de acceso offline, la aplicación no almacena la contraseña del usuario en texto plano. En su lugar, genera y almacena de forma segura un verificador criptográfico derivado de la contraseña.

Los datos relacionados con la sesión activa, tales como el token de autenticación y determinada información básica del usuario, se almacenan utilizando mecanismos de almacenamiento seguro proporcionados por el dispositivo.

4. Uso de la información

La información tratada por SST EduRisk se utiliza exclusivamente para propósitos relacionados con el funcionamiento de la aplicación, incluyendo:

  • Autenticar a los usuarios.
  • Controlar permisos de acceso según el rol asignado.
  • Crear y administrar matrices IPERC.
  • Identificar peligros y evaluar riesgos.
  • Gestionar medidas y controles preventivos.
  • Registrar seguimientos relacionados con SST.
  • Permitir determinadas funciones sin conexión a Internet.
  • Sincronizar información local con el servidor autorizado.
  • Generar información, reportes o documentos solicitados por el usuario.
  • Mantener la seguridad y funcionamiento de la aplicación.

5. Funcionamiento online y offline

SST EduRisk está diseñada para funcionar mediante un modelo online y offline.

Cuando existe conexión a Internet, la aplicación puede comunicarse con el servidor autorizado para consultar, registrar o actualizar información.

Cuando no existe conexión, determinadas operaciones pueden almacenarse temporalmente en el dispositivo. Posteriormente, cuando la conexión esté disponible, los cambios pueden sincronizarse con el servidor.

6. Almacenamiento local

Parte de la información necesaria para el funcionamiento offline puede almacenarse localmente en el dispositivo móvil mediante una base de datos de la aplicación y mecanismos de almacenamiento seguro.

Esta información se utiliza para permitir la continuidad de las funciones autorizadas de SST EduRisk y para gestionar la posterior sincronización con el servidor cuando exista conectividad.

7. Conexión a Internet

SST EduRisk puede utilizar la conexión a Internet del dispositivo para comunicarse con los servicios correspondientes del sistema.

La conexión puede utilizarse, entre otras finalidades, para:

  • Iniciar sesión.
  • Consultar información autorizada.
  • Registrar y actualizar información.
  • Sincronizar datos pendientes.
  • Comprobar la disponibilidad del servidor.

8. Publicidad

SST EduRisk no utiliza publicidad de terceros.

La aplicación no utiliza la información de los usuarios para mostrar anuncios personalizados.

9. Venta de información personal

SST EduRisk no vende la información personal de sus usuarios.

Los datos gestionados mediante la aplicación se utilizan para proporcionar las funcionalidades correspondientes al sistema de Seguridad y Salud en el Trabajo.

10. Compartición de información

SST EduRisk no comparte información personal con terceros con fines publicitarios o comerciales.

La información podrá ser tratada por la infraestructura técnica necesaria para proporcionar el servicio, como el servidor en el que opere el sistema, siempre dentro de las finalidades descritas en esta Política de Privacidad.

También podrá proporcionarse información cuando exista una obligación legal válida o un requerimiento de una autoridad competente, según corresponda.

11. Conservación de la información

La información se conservará durante el tiempo necesario para proporcionar las funcionalidades de SST EduRisk, cumplir las necesidades administrativas de la organización que utiliza el sistema y atender las obligaciones legales que resulten aplicables.

Parte de la información almacenada localmente puede permanecer en el dispositivo mientras sea necesaria para el funcionamiento offline o hasta que sea eliminada mediante los mecanismos disponibles en la aplicación, la desinstalación de la aplicación o la administración correspondiente del sistema.

12. Eliminación de datos

Los usuarios pueden solicitar información relacionada con la eliminación, corrección o actualización de sus datos mediante el correo electrónico de contacto indicado al final de esta Política de Privacidad.

Las solicitudes serán evaluadas considerando las características de la cuenta, las obligaciones aplicables y la necesidad de conservar determinados registros asociados a las actividades de Seguridad y Salud en el Trabajo.

13. Seguridad de la información

SST EduRisk aplica medidas técnicas orientadas a proteger la información gestionada por la aplicación contra accesos, modificaciones o usos no autorizados.

Entre las medidas utilizadas se encuentran mecanismos de autenticación, control de acceso por roles, almacenamiento seguro de determinada información de sesión y mecanismos de protección para las credenciales utilizadas en el acceso offline.

No obstante, ningún sistema informático puede garantizar una seguridad absoluta. Los usuarios también son responsables de proteger las credenciales y el dispositivo desde el cual acceden a SST EduRisk.

14. Permisos del dispositivo

SST EduRisk solicita únicamente los permisos del dispositivo que sean necesarios para proporcionar las funcionalidades habilitadas.

La aplicación requiere acceso a Internet para las operaciones que necesitan comunicación con el servidor.

Si una funcionalidad permite seleccionar imágenes, documentos u otros archivos como evidencia, el acceso correspondiente se utilizará únicamente cuando el usuario ejecute voluntariamente esa función.

15. Datos sensibles

Debido a la naturaleza de un sistema de Seguridad y Salud en el Trabajo, los usuarios deben evitar introducir información personal que no sea necesaria para las finalidades de la aplicación.

La información registrada debe limitarse a aquella necesaria para las funciones autorizadas de SST e IPERC.

16. Menores de edad

SST EduRisk está orientada a usuarios autorizados encargados de procesos de gestión de Seguridad y Salud en el Trabajo.

La aplicación no está diseñada como un servicio dirigido a menores de edad ni tiene como finalidad recopilar directamente información personal de menores.

17. Servicios de terceros

La aplicación puede utilizar componentes técnicos o bibliotecas necesarias para proporcionar funciones como conectividad, almacenamiento local, generación de documentos y funcionamiento de la aplicación móvil.

SST EduRisk no utiliza estos componentes con la finalidad de vender información personal ni crear perfiles publicitarios de los usuarios.

18. Responsabilidad del usuario

El usuario se compromete a utilizar SST EduRisk únicamente para las finalidades autorizadas y a proteger adecuadamente sus credenciales de acceso.

El usuario no debe compartir su contraseña ni permitir el acceso no autorizado a su cuenta o dispositivo.

19. Cambios en esta Política de Privacidad

Esta Política de Privacidad podrá actualizarse cuando se incorporen nuevas funcionalidades, cambien las prácticas de tratamiento de información o resulte necesario adaptarla a nuevos requisitos técnicos o legales.

La versión vigente estará disponible públicamente en esta misma página y mostrará la fecha de su última actualización.
